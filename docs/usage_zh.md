# 使用指南

## 设置课表

1. 打开「课表设置」，填写第一周的周一、学期长度（1–30 周）以及每日 12 节课的起止时间。
2. 选择「使用空白课表」清除示例，或通过「导入课表」录入已有安排。确认前检查是否替换现有课程。
3. 点击「添加课程」或课表空白格录入；点击课程卡片可编辑或删除。
4. 使用箭头或侧边日历切换周次，按课程名、教师或教室搜索，也可切换至列表视图。

保存或导入前会提示时间冲突。允许保留重叠课程，并在课表中并排展示。「即将开始」按实际日期计算，与当前查看的周次独立。

## 界面语言

通过右上角语言菜单选择 **English**、**简体中文**或 **繁體中文**。首次访问优先匹配浏览器支持的语言，无法匹配时使用简体中文；手动选择后按当前浏览器和站点保存偏好。日期、控件、校验提示和 Excel 模板都会随语言切换。示例课程仅在显示时翻译；自己录入的课程名、教师、地点、备注及自定义学期名称保留原文。

## 外观模式

右上角的太阳、月亮和显示器按钮分别切换「浅色模式」「深色模式」和「跟随系统」。默认跟随设备外观，并在系统主题变化时自动切换。手动选择浅色或深色后固定使用该模式；偏好单独保存在当前浏览器，不影响课表数据。

## 导入 Excel 或 CSV

打开「导入课表」，下载 Excel 模板，替换或删除示例行。选择或拖入文件，检查预览后确认追加或全部替换。

模板与导出的表头使用当前界面语言。导入时始终兼容 English、简体与繁体表头，如 `課程名稱`、`開始節次`、`結束節次`、`週次`、`教師`、`備註`；也接受 `週一`–`週日`、`禮拜一`–`禮拜日`。周次可使用 `单/双`、`單/雙` 或 `odd/even`，例如 `1-16(odd)`、`2-16(雙)`。

每行对应一个每周上课时段；同一门课有多个时段时分行填写。第一个非空行为表头，列顺序可以调整。

| 中文表头   | 英文表头  | 必填 | 示例或可用值                                   |
| ---------- | --------- | ---- | ---------------------------------------------- |
| `课程名称` | `name`    | 是   | `高等数学`                                     |
| `星期`     | `day`     | 是   | `1`–`7`（周一至周日）、`周一`、`Monday`、`Mon` |
| `开始节次` | `start`   | 是   | `1`–`12`                                       |
| `结束节次` | `end`     | 是   | `1`–`12`，不早于开始节次                       |
| `周次`     | `weeks`   | 是   | `1-16`、`1,3,5`、`1-16(单)`、`2-16(双)`        |
| `教室`     | `room`    | 否   | `A-302`                                        |
| `教师`     | `teacher` | 否   | `陈老师`                                       |
| `备注`     | `note`    | 否   | `带教材`                                       |

`单`、`双`分别表示单周、双周，也可使用繁体或 `odd`、`even` 标记。周次不能超出设置的学期长度。

```csv
课程名称,星期,开始节次,结束节次,周次,教室,教师,备注
高等数学,周一,1,2,1-16,A-302,陈老师,带教材
设计思维,周三,5,6,"1,3,5",创意工坊,周老师,
```

- 支持 `.xlsx` 和 UTF-8 `.csv`，最大 10 MiB、2,000 条安排。XLSX 工作表使用范围需控制在含表头的 2,001 行内。
- Excel 读取第一个非空工作表，预览显示工作表名称；空数据行会跳过。
- 错误行会阻止整次导入，修正后重新选择文件。确认前不会写入课程。
- 预览最多显示 50 条有效行；全部错误解决后，确认会导入所有有效行。
- 旧 `.xls` 需先另存为 `.xlsx`。暂不自动识别合并单元格的周视图课表或任意学校导出格式。

## 导出与存储

点击课表上方的下载图标，将全部课程安排导出为 Excel，导出的课程可再次导入。导出不包含学期设置、作息时间或自定义颜色。

课程和设置自动保存在当前浏览器的 `localStorage` 中。同源且数据格式兼容时，正常更新站点会保留数据；清除站点数据会删除课表，隐私窗口关闭后也可能丢失数据。

不同浏览器、设备、端口和域名的存储相互独立。迁移时先从旧地址导出，在新地址导入，并按需重新填写学期设置。若出现保存失败提示，请在关闭页面前导出。

## 当前范围

目前管理一份按周重复的课程表，尚未实现账号、云同步、教务系统抓取、推送通知、单次调课、考试或多课表管理。字体来自 Google Fonts，无法访问时使用系统字体；表格解析在浏览器内完成。
