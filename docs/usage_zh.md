# 使用指南

## 设置课表

1. 从侧栏底部打开「课表设置」，填写「本学期第一天」、学期长度（1–30 周）和「每日节数」（1–30，默认 12）。开始日期可选任意星期，作息起止时间按需填写。使用 24 小时制 `HH:mm`（如 `08:00` 或 `14:30`）。作息时间默认留空，已有课表保存的时间保持不变。
2. 选择「使用空白课表」清除示例，或通过「数据管理」录入已有安排。确认前检查是否替换现有课程。
3. 点击「添加课程」或课表空白格录入；点击课程卡片查看详情，再选择「编辑课程」修改或删除。「开始时间/节次」与「结束时间/节次」可填写整数节次（如 `1`、`2`）或 24 小时制时间（如 `08:00`、`09:40`）。两端须使用同种格式，时间课程须在同一天内结束。
4. 使用箭头或侧边日历切换周次，按课程名、教师或教室搜索，可通过侧栏的「全部课程」集中查看；课表固定使用周视图。

每周按周一至周日排列。例如周四开学时，首周从周四开始有课，之前的课程不会显示。增加每日节数会新增空白作息行；减少节数前，需要先调整超出新范围的课程。

保存或导入前会提示时间冲突。允许保留重叠课程，并在课表中并排展示。「即将开始」时间线预览跨日期的三条安排，同时保留正在上课或时间不确定的近期课程。桌面端和平板横屏时位于右栏，手机和平板竖屏时横向置于课表上方；课程标签沿用课程配色，备注紧接课名。时间线按实际日期计算，与查看周次独立。侧栏日历下方的「本周进度条」表示所选周已过去的时间，不是课程完成比例。兔子卡片在桌面端和平板横屏时位于时间线下方，手机和平板竖屏时位于课表下方。已结束课程保留原配色，并叠加轻微暗色遮罩。未填写完整作息时，显示日期、节次及时间未设置提示；今日作息时间不完整的节次课程保持可见，不会被误判为正在上课。只有开始时间明确且先后顺序可确定时才标记「下一次课程」，不会跳过时间未知的课程而将之后的日期标为下一次。直接填写时间的课程独立于每日作息，在对应日期的「按时间」区域展示。若缺少作息导致无法判断两类课程是否冲突，会明确提示。

## 界面语言

通过右上角语言菜单选择 **English**、**简体中文**或 **繁體中文**。首次访问优先匹配浏览器支持的语言，无法匹配时使用 English；手动选择后按当前浏览器和站点保存偏好。日期、控件、校验提示和 Excel 模板都会随语言切换。示例课程仅在显示时翻译；自己录入的课程名、教师、地点、备注及自定义学期名称保留原文。

locale 使用 `en`、`zh-Hans` 和 `zh-Hant`，之前保存的 `zh-CN` / `zh-TW` 偏好会自动迁移。

## 首页显示

通过课表上方的「显示」菜单切换「显示周末」、「显示教师」与「显示备注」，选择会保存在当前浏览器。课表卡片中的教师默认隐藏，开启后单独显示一行。备注默认隐藏，开启后在课程卡片、列表和「即将开始」中展示非空内容。长备注在首页省略显示，详情中始终可完整查看；关闭展示不会删除备注。

隐藏周末时，如果当前周末有课程，页面会提供显示提示。桌面端由课表决定内容高度，右侧组件适配该高度并与课表底边对齐；即将开始的条目在空间不足时滚动，页面底部保留留白。所有屏幕尺寸下，侧栏「使用指南」（Getting started）下方的「源代码」链接都在新标签页打开 GitHub 仓库；移动端先打开导航菜单，再滚动到侧栏底部。

## 外观模式

右上角的太阳、月亮和显示器按钮分别切换「浅色模式」「深色模式」和「跟随系统」。默认跟随设备外观，并在系统主题变化时自动切换。手动选择浅色或深色后固定使用该模式；偏好随完整快照保存在当前浏览器，不改变课程内容。

## 导入 Excel 或 CSV

从侧栏打开「数据管理」，下载 Excel 模板，替换或删除示例行。选择或拖入文件，检查预览后确认追加或全部替换。

模板与导出的表头使用当前界面语言。起止列可填写节次或实际时间，同一行两端格式须一致。新版表头使用「开始时间/节次」「结束时间/节次」，仍兼容旧的节次表头。导入时始终兼容 English、简体与繁体表头，如 `課程名稱`、`開始節次`、`結束節次`、`週次`、`教師`、`備註`；也接受 `週一`–`週日`、`禮拜一`–`禮拜日`。周次可使用 `单/双`、`單/雙` 或 `odd/even`，例如 `1-16(odd)`、`2-16(雙)`。

英文备注表头使用 `remark`，仍兼容旧的 `note` / `notes` 以及 `remarks`。

每行对应一个每周上课时段；同一门课有多个时段时分行填写。第一个非空行为表头，列顺序可以调整。

| 中文表头        | 英文表头  | 必填 | 示例或可用值                                             |
| --------------- | --------- | ---- | -------------------------------------------------------- |
| `课程名称`      | `name`    | 是   | `高等数学`                                               |
| `星期`          | `day`     | 是   | `1`–`7`（周一至周日）、`周一`、`Monday`、`Mon`           |
| `开始时间/节次` | `start`   | 是   | 节次 `1` 至已设置的每日节数 或 `HH:mm`                   |
| `结束时间/节次` | `end`     | 是   | 节次 `1` 至已设置的每日节数 或 `HH:mm`，格式须与开始一致 |
| `周次`          | `weeks`   | 是   | `1-16`、`1,3,5`、`1-16(单)`、`2-16(双)`                  |
| `教室`          | `room`    | 否   | `A-302`                                                  |
| `教师`          | `teacher` | 否   | `陈老师`                                                 |
| `备注`          | `remark`  | 否   | `带教材`                                                 |

`单`、`双`分别表示单周、双周，也可使用繁体或 `odd`、`even` 标记。周次不能超出设置的学期长度。

```csv
课程名称,星期,开始时间/节次,结束时间/节次,周次,教室,教师,备注
高等数学,周一,1,2,1-16,A-302,陈老师,带教材
设计思维,周三,14:00,15:30,"1,3,5",创意工坊,周老师,
```

- 支持 `.xlsx` 和 UTF-8 `.csv`，最大 10 MiB、2,000 条安排。XLSX 工作表使用范围需控制在含表头的 2,001 行内。
- Excel 读取第一个非空工作表，预览显示工作表名称；空数据行会跳过。
- 错误行会阻止整次导入，修正后重新选择文件。确认前不会写入课程。
- 预览最多显示 50 条有效行；全部错误解决后，确认会导入所有有效行。
- 旧 `.xls` 需先另存为 `.xlsx`。暂不自动识别合并单元格的周视图课表或任意学校导出格式。

## 导出与存储

通过「数据管理 → 导出全部数据（JSON）」备份全部课程、ID、备注、颜色、学期设置、每日作息、语言、外观和显示偏好。本地保存失败时，导出仍包含内存中的当前修改。通过「数据管理」校验与预览，确认后完整替换当前数据；无效、损坏或不支持的文件不会修改当前状态。详见[备份格式与恢复说明](backup-format_zh.md)。

「数据管理 → 导出 Excel 课表」用于表格编辑及随后追加／替换课程，不包含学期设置、每日作息或自定义颜色。

修改统一保存为完整快照。写入后会回读校验，正常保存时首页不显示状态行。失败时保留内存修改，可导出 JSON 或重试。损坏存储保留原文并提供下载。其他标签页修改数据后暂停覆盖；请先导出当前修改，再确认「载入已保存版本」。JSON 恢复也会检查预览期间已保存数据是否发生变化。

不同浏览器、设备、端口和域名使用独立存储。完整迁移请从旧地址导出 JSON，在新地址恢复。无痕模式可能在最后一个无痕窗口关闭时删除数据；普通浏览器存储也可能被清除或回收。应用不猜测是否处于无痕模式，保存成功后仍应保留独立备份。

## 当前范围

目前管理一份按周重复的课程表，尚未实现账号、云同步、教务系统抓取、推送通知、单次调课、考试或多课表管理。生产构建随站点提供 Plus Jakarta Sans 和 Noto 字体分片，加载失败时使用系统字体；表格解析在浏览器内完成。

顶部语言选择框与外观切换控件统一为 40px 高度，移动端保持一致。
